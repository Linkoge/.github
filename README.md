# Linko organization profile

The public GitHub organization profile lives in [`profile/README.md`](profile/README.md).

## Brand assets

The logo variants in `profile/assets/` reuse the logo published at
[linko.ge/assets/logo-white.svg](https://linko.ge/assets/logo-white.svg).
The original paths and red accent are preserved. The view box is cropped to reduce
empty space; the light-theme variant uses Linko’s website background color for the
wordmark. The profile selects a variant for GitHub’s light or dark theme.

Only public project information and public website branding are included.
The badges describe technologies used by Linko Dev Panel.
