# Original Linko hero artwork

These four SVGs are byte-for-byte copies from `Linkoge/.github` commit
`4a186cada724733540861b7440fe9a79ff4f5076`, before the red-dot adjustment.

The active hero assets move only the logo accent by `translate(-15 -6)`.
The October 5 website logo editor (`cryptiama/Linko`, commit `0037fd8`)
changes `--dot-top` from `-9px` to `-11px` and `--dot-right` from
`-26px` to `-21px`. The original vector is in the editor’s 3× PNG coordinates,
so the matching translation is 15 units left and 6 units up.
The wordmark, orbit paths, dot shape, colors, network lines and crops are preserved.
